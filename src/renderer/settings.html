DeepSeek Harness

Where the harness runs from

Version is available.

i

The working directory the harness runs in for a managed install — the folder the agent reads and writes files in. Defaults to your home folder.

Plugins

pkg for the latest, offered updates later, or pkg@version to pin it exactly and never be offered an update. The notification hook bridge is pre-seeded below.

    Each enabled server's tools become available to the agent under its own name. With this off, no server is contacted and nothing it offers reaches the model.

    Adding or removing a server saves it straight away, to the mcp.json its scope names. The two switches on this tab are saved with the rest of the form.

    This app's own views

    Adds the view tools the agent can call: show a file in the editor, open a page in the Web tab, show a change it proposes before making it, read your selection, and drive the built-in browser.

    Global servers

    One process shared by every session, so a server that writes files uses one directory for all of them. Kept in ~/.dsh/mcp.json.

    MCP is switched off, so none of these servers are connected. Tick Connect to MCP servers above.
